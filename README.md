# SmartQueue

Электронная очередь для живых очередей: в кабинет преподавателя, на пересдачу, в кофейню.

Организатор создаёт очередь и получает код из 6 символов и QR-код. Участники встают в очередь по коду через приложение, сайт или телеграм-бот, видят своё место и получают уведомление, когда до них остаётся пара человек. Стоять под дверью не нужно.

Два вида очередей:
- **обычная** — без оператора: первый в очереди сам нажимает «Следующий», когда прошёл. Если он забыл, через 10 минут управление может забрать второй;
- **бизнес** — для кофейни или приёма: оператор вызывает следующего и отмечает, кто прошёл.

Очередь одна на все платформы: встал через бота — тебя видно и на сайте, и в приложении.

## Технологии

- сервер — Python, FastAPI
- база — PostgreSQL
- приложение и сайт — Flutter
- запуск — Docker Compose

## Запуск

```
cp .env.example .env
docker compose up --build
```

Сервер: http://localhost:8080/api/v1/health
API: http://localhost:8080/docs

## Тесты

```
cd server
pip install -r requirements-dev.txt
pytest
```

Клиент (Flutter):

```
cd client
flutter create . --platforms=web,android
flutter pub get
flutter test
flutter run -d chrome --dart-define=API_URL=http://localhost:8080
```

Тест-кейсы для ручной проверки — docs/test-cases.md
